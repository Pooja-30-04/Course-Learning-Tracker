# Course-Learning-Tracker
A Django-based Learning Management System (LMS) that enables students to enroll in courses, track learning progress, complete quizzes, and view performance analytics, with an admin panel for managing courses, lessons, quizzes, and student data.

Overview:

A Django-based Learning Management System designed to help students manage courses, track lesson completion, take quizzes, and monitor their learning performance.

Features: User registration and authentication Course browsing and enrollment Lesson management Progress tracking MCQ-based quizzes Automatic quiz evaluation Performance analytics Admin panel Course and lesson management Quiz and question management

Technologies: Python Django SQLite HTML CSS JavaScript Tailwind CSS

User Workflow:

Register/Login -> Browse Courses -> Enroll in Course -> Complete Lessons -> 100% Course Completion -> Quiz Unlocked -> Attempt Quiz -> View Result & Performance
